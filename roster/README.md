# Class roster — your first Pull Request (Week 1 lab)

Your first Pull Request in this course is a practice run. It adds **one file**
to this folder, named after your GitHub username:

```
roster/YOUR-GITHUB-USERNAME.md
```

Put only this one line in it — **no real name, roll number, phone number or
email**. This repository is public.

```
Hello from YOUR-GITHUB-USERNAME
```

Then commit it on a branch called `roster`, push, and open a Pull Request
(the steps are in `docs/submission-workflow.md`, "One-time setup", step 8).

The **Submission guard** check makes sure the file is named after the account
that opened the PR. Your instructor merges roster PRs. This is the only kind
of PR that gets merged in this course. Having it merged also means GitHub
stops asking your instructor to approve your automatic checks later.

Your instructor links your GitHub username to your roll number privately.
Don't put your roll number in this repository.
