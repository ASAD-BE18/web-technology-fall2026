## Q1. Setting `width` on the menu links did nothing until you added `display: inline-block`. Why?

Your answer: by default menu links are inline elements so the width property does not work on them when we use `display: inline-block` we can set their width and height while keeping them on the same line

## Q2. Does `display: flex` go on the parent or on the children? What happens to the children when you add it?

Your answer: `display: flex` is applied to the parent element not the children when we add it the children automatically arrange themselves in a row by default making them easier to align and space
