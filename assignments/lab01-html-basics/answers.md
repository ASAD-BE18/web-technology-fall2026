## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer: <ol> is an ordered list that shows numbers or letters in a specific sequence, while <ul> is an unordered list that shows bullet points without any order. I would use <ol> for steps to make tea because the order matters, and I would use <ul> for a list of my favorite hobbies because the order does not matter.


## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: Every <img> must have an alt attribute because it describes the image when the image cannot load and it helps with accessibility. It is used by screen readers for blind users and by search engines to understand what the image is about.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link like hobby.html points to a file inside the same website and does not include the full domain name. An absolute link like https://example.com includes the full URL and points to a page on another website. I would use a relative link for navigation inside my own site and an absolute link to go to Google or YouTube.
