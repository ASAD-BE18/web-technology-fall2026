### Question 1: What is the purpose of the DOCTYPE declaration in HTML?
The DOCTYPE declaration tells the web browser which version of HTML is being used on the webpage. It ensures that the browser renders the page correctly in standards mode rather than quirks mode.

### Question 2: Explain the difference between an ordered list and an unordered list.
An ordered list creates a numbered list where the sequence of items matters, using the ol tag. An unordered list creates bullet points where the order of items does not matter, using the ul tag.

### Question 3: What is the difference between an absolute URL and a relative URL?
An absolute URL contains the complete address of a webpage including the protocol like https and domain name. A relative URL points to a file path relative to the current folder location on the server.
