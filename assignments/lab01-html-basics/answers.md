## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer: An `<ol>` tag creates a numbered list where the chronological order of items matters, while a `<ul>` tag creates a bulleted list for items that do not require any specific ranking. For example, I would use an ordered list to display a cooking recipe and an unordered list for shopping list.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: Every image needs an alt attribute to provide a descriptive textual alternative if the image file fails to load or display correctly on the user's screen. This text description is primarily used by visually impaired people relying on screen reader software to understand what the graphic represents.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link paths to a file hosted locally within the same folder structure of your own project repository without specifying a domain name. In contrast, an absolute link requires a complete website URL address starting with https to target external independent webpages over the internet.
