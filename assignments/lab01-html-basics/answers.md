## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer:
An `<ol>` element creates an ordered list where items are displayed with numbers or sequential markers, making order essential. On the other hand, a `<ul>` element creates an unordered list with bullet points, where the order of items does not matter. For example, an `<ol>` is ideal for step-by-step recipe instructions, whereas a `<ul>` is suitable for a simple shopping list.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer:
The `alt` attribute provides alternative text that describes an image if it fails to load on the screen. It is primarily used by screen readers to assist visually impaired users in understanding the image content, and by search engine crawlers for SEO indexing. Additionally, it helps general users understand what the image was supposed to show when internet connections are slow.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer:
A relative link points to a file or page within the same repository or server using its path relative to the current file, such as `hobby.html`. Conversely, an absolute link provides the full web address including the protocol, such as `https://google.com`, to point to a page anywhere on the internet. Relative links are best for linking local files in a website project, while absolute links are necessary for connecting to external domain websites.
