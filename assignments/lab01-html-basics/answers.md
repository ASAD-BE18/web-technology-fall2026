## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?



A relative link means if you have your own website and this link open another page of same website  , for example, `hobby.html`.
Example:
`<a href="hobby.html">My Hobbies</a>`

An absolute link means if you click this link you can move another website, for example, W3Schools.
Example:
`<a href="https://www.w3schools.com/html/">Learn HTML</a>`
