## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: The alt attribute is a short text that describes the picture. It is used when the picture cannot load (for example, when laptop.jpg is missing), and by people who cannot see the screen, such as blind users with a screen reader.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link only needs the file name because the file is in the same folder. An absolute link like https://developer.mozilla.org gives the full web address of a page on another website.
