## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?
A relative link points to another file within the same website or project, such as hobby.html . 
An absolute link includes the full web address, such as http://www.w3schools.com/, and can link to an external website.
