## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer: The `<ol>` tag is used to create an ordered list with numbers, while the `<ul>` tag is used to create an unordered list with bullet points. For example, I would use `<ol>` to list my goals in order and `<ul>` to list my interests.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: The alt attribute provides a description of an image if it cannot be displayed. It is also used by screen readers to help visually impaired people understand the image.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link connects to a file within the same website, such as hobby.html. An absolute link contains the complete web address, such as https://www.wikipedia.org, and can link to another website.
