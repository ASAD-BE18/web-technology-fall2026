## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer:

An `<ol>` is used to make a numbered list, like 1, 2, 3. A `<ul>` is used to make a list with bullet points, like a list of my hobbies. I would use `<ol>` for steps and `<ul>` for things that do not need an order.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer:

The `alt` attribute gives a text description of an image. Screen readers use this text to help people who cannot see the image. It is also helpful when an image does not load.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer:

A relative link points to another file using its path, like `hobby.html`. An absolute link uses the full web address, like `https://developer.mozilla.org/`. A relative link can connect pages in my project, while an absolute link can open an external website.
