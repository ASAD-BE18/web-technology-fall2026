## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Answer= The `<ol>` tag creates an ordered list with numbers, while the `<ul>` tag creates an unordered list with bullet points. I would use `<ol>` for instructions that must be followed in order, and `<ul>` for listing my hobbies.

### Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Answer= Every `<img>` should have an `alt` attribute to describe the image if it cannot load. Screen readers use the alt text to help visually impaired people understand what the image shows.

### Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Answer= A relative link points to a file using a path relative to the current page, such as `hobby.html`. An absolute link contains the full URL, including the protocol and domain, such as `https://www.example.com`, and can point to a page on another website.
