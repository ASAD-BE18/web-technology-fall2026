## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer:The '<ol>' tag makes an ordered (numbered) list, while the '<ul>' tag makes an unordered list with bullet points. I would use '<ol>' when the order matters, like my three goals for this semester, and I would use '<ul>' when the order does not matter, like a list of things I like.

 
## Q2.Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer:The 'alt' attribute gives a text description of the picture, so the page still makes sense if the image does not load. It is used by screen readers to describe the image to blind or visually impaired users, and by search engines to understand what the picture shows.


## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer:A relative link like'`hobby.html' points to a file by its location compared to the current page, so it only works for files inside my own project folder. An absolute link like `https://developer.mozilla.org/...` has the full web address including the protocol and domain, so it can take the visitor to any other website.
