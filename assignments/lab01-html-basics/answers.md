## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer: An <ol> creates an ordered list with numbers, so it is useful when the order of items matters, such as steps in a recipe. 
A <ul> creates an unordered list with bullet points, which is useful when the order does not matter, such as a list of my interests.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: The alt attribute provides a text description of an image. It helps people who use screen readers understand the image, and the text can also appear if the image cannot be displayed.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link points to another file in the same project, such as hobby.html, without giving the complete web address. An absolute link includes the full URL of a website, such as https://www.w3.org/, and takes the user to that website.
