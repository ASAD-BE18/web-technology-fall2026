## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer: <ol> is used to display an ordered list where items have numbers. For example, I can use it to show the steps for creating a website. <ul> is used to display an unordered list with bullet points, such as a list of my hobbies.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: The alt attribute provides a text description of an image if the image cannot be displayed. Screen readers also read this description for people who cannot see the image clearly or are blind.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link points to another file using its path, such as hobby.html, usually within the same website or folder. An absolute link contains the complete URL, such as https://www.w3schools.com/, and points to a specific web address.
