## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link points to a file or page using its location relative to the current webpage. It does not need the full website address.
For Example: 
<a href="hobby.html">My Hobby</a>
An absolute link contains the complete URL, including the protocol (https://) and domain name. It can link to a page on another website.
For Example: 
<a href="https://www.google.com">Google</a>
