## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer: <ol> stands for Ordered List. It displays items in numbered order.
<ul> stands for Unordered List. It displays items with bullet points.
Example: Use <ol> for semester goals and <ul> for hobbies.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer:The alt attribute provides a text description of an image.
It can help users understand the image if it fails to load.
Screen readers use this description to help visually impaired people understand images.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer:A relative link points to another file within a website, such as hobby.html.
An absolute link contains the complete web address, such as https://www.example.com.
Your index.html page uses a relative link to open hobby.html, while an external website link uses an absolute URL.
