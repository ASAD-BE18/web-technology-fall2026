## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.
Your answer: An ordered list `<ol>` displays items with numbers where sequence matters, such as listing your top 3 semester goals. An unordered list `<ul>` displays bullet points for items where order does not matter, such as a list of personal hobbies.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: The `alt` attribute provides a text description of an image for accessibility when the image cannot be displayed. Visually impaired people who rely on screen readers use it to understand what the picture shows, and browsers also display this text if the image link is broken.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: A relative link points to a file within the same repository or directory structure, such as `hobby.html`. An absolute link provides the full web address including `https://` to link directly to an external website on the internet.
