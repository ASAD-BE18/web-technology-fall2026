## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer: 
The main difference between <ol> and <ul> is how they display list items. The <ol> creates a numbered list, while <ul> creates a bulleted list. Use a numbered list (like 1, 2, 3) when order matters, such as steps to follow, and a bulleted list for items when numbering is not important like hobbies.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer: 
The alt attribute describes an image in text. It helps when an image cannot load, and Screen Readers use it to explain images to people who cannot see them clearly.
e.g.
<img src="https://encrypted-tbn0.gstatic.com/images?q=tbn:ANd9GcQW59gMA-dt5uk8GiXbCJ7pe_6teKtECXw0I9OWnnxYDg&s=10" alt="A book lying on a table">

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer: Difference between Relative link and Absolute link: 

A relative link points to a file or location relative to the current page, such as hobby.html
e.g. <a href="hobby.html">My Hobby</a>
An absolute link contains the complete web address, including the protocol and domain, such as https://www.google.com/
e.g. <a href="https://www.google.com/">Google</a>
