## Q1. What is the difference between `<ol>` and `<ul>`? Give one example of when you would use each.

Your answer:The <ol> tag is used to create an ordered list in which items appear in a numbered sequence. For example, I would use <ol> to show the steps for creating an account. The <ul> tag is used to create an unordered list with bullet points, such as a list of my hobbies.

## Q2. Why must every `<img>` have an `alt` attribute? Who uses it?

Your answer:The alt attribute provides a text description of an image on a webpage. Screen readers use this description to help visually impaired users understand the image, and it can also appear if the image cannot load.

## Q3. Your page links to `hobby.html` and to `https://...`. What is the difference between a relative link and an absolute link?

Your answer:A relative link points to a file or page using a path relative to the current page, such as hobby.html. An absolute link contains the complete URL, including the protocol and domain name, such as https://www.example.com. Relative links are useful for linking pages within the same website, while absolute links are commonly used to link to external websites.
